# Модуль 7. CI/CD и безопасный выкат

## Цели задания

- Собрать CI/CD-пайплайн для ML-сервиса.
- Показать безопасные стратегии выката: canary, blue-green, A/B.
- Обеспечить воспроизводимость сборки и автоматический откат.

## Условия

Нужно построить CI/CD для ML-сервиса (FastAPI + RandomForest на ирисах) и
продемонстрировать безопасный выкат. Я настроил этапы lint / test / train / build, два
образа версий, canary на nginx (10 -> 25 -> 50 -> 100%) и blue-green-переключение, план
A/B-теста и автооткат по неуспешному health-check. ADR обосновывают выбор canary вместо
blue-green.
