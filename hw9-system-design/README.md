# Модуль 9. Проектирование системы целиком

## Цели задания

- Сравнить архитектуры ML-конвейеров и стратегии переобучения.
- Спроектировать и написать DAG Airflow для прикладной ML-системы.

## Условия

Задание из двух частей. Первая - сравнить архитектуры ML-конвейеров и триггеры
переобучения на четырёх кейсах. Вторая - спроектировать и написать DAG Airflow для
расчёта складских запасов сетевого магазина: ожидание на S3 -> ветвление по решению о
переобучении -> TaskGroup обучения -> сравнение с production -> промоут в MLflow. В папке
также лежит инфраструктура Terraform и IaC-воркфлоу GitHub Actions.

## Что внутри

- [`ML-HW_9-main/`](ML-HW_9-main/) - проект: ноутбук-дизайн, DAG Airflow, Terraform `infra/`, IaC-воркфлоу.
- [`ML-HW_9-main/HW9_Design_Вольхин_Сергей.ipynb`](ML-HW_9-main/HW9_Design_Вольхин_Сергей.ipynb) - решение: сравнение архитектур и DAG переобучения.
