# Модуль 5. Воспроизводимый ML-пайплайн

## Цели задания

- Собрать воспроизводимый ML-контур: данные под версионированием, эксперименты в трекере, фичи в фичесторе.
- Связать этапы пайплайна так, чтобы перезапуск был детерминированным.

## Условия

Нужно построить воспроизводимый пайплайн для классификации вин (Wine, 3 класса, 13
признаков): датасет под DVC, эксперименты в MLflow, фичи в Feast на PostgreSQL. Я собрал
пайплайн `dvc.yaml` (prepare -> train) для RandomForest, логировал параметры, метрики и
артефакты в MLflow и материализовал фичи в онлайн- и офлайн-сторы.
